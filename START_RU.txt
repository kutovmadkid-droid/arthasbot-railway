AURORA SHOP — РУЧНАЯ КРИПТООПЛАТА

СЦЕНАРИЙ
Покупатель выбирает товар → кошелёк и сеть → переводит криптовалюту →
нажимает «Я оплатил» → отправляет фото-скриншот → вы проверяете поступление.
Никакой автоматической проверки блокчейна. Stars не добавлены.

Если оплата пришла: подтвердите и отправьте данные покупки одним сообщением,
затем нажмите кнопку отправки покупателю.
Если не пришла: нажмите «Отклонить оплату», напишите причину (до 320 символов),
проверьте предпросмотр и нажмите «Отклонить и отправить причину».
Покупатель получит фото, отказ, ваш комментарий, поддержку и главное меню.
Причина сохраняется в истории. Пока вы не подтвердили отправку, заказ
остаётся на проверке. Можно изменить текст или отменить отказ.

ПРАВИЛА ПЛАТФОРМЫ
Telegram требует Stars для цифровых товаров и подписок внутри Telegram.
Криптооплата таких продаж противоречит правилам платформы и может привести
к ограничениям бота. Ручная проверка скриншотов не меняет это требование.
Источник: https://core.telegram.org/bots/payments-stars#faq
Технический модуль криптооплаты оставлен по вашему запросу; это не означает
подтверждения соответствия правилам Telegram.

ЗАПУСК В RAILWAY
1. Распакуйте архив и загрузите содержимое aurora-shop в корень GitHub repo.
   В корне: Dockerfile, railway.json, requirements.txt и папки shop/assets/tests.
   Не загружайте ZIP вместо исходников. Не публикуйте токен или базу.
2. В @BotFather: /newbot → получите BOT_TOKEN.
3. Подготовьте свой числовой Telegram ID для ADMIN_IDS (не @username).
4. Railway: New Project → Deploy from GitHub repo → выберите репозиторий.
5. Подключите к сервису Volume с Mount path /data.
6. Variables:
   BOT_TOKEN = ваш реальный токен
   ADMIN_IDS = ваш числовой ID (несколько через запятую)
   DATA_DIR = /data
   ALLOW_MANUAL_CRYPTO_CHECKOUT = true
   Последний флаг технически включает выбранный вами ручной криптомодуль.
   Без него приложение по умолчанию не разрешает оформление оплаты.
7. Одна реплика. Команда запуска: python -m shop.
   Dockerfile, healthcheck /health уже настроены. Домен не требуется.
8. Deploy. Каждый администратор открывает бота и нажимает /start, затем /admin.
9. Настройте поддержку, условия покупки, категории и товары. Задайте
   кошелёк, монету USDT/USDC, сеть, описание и фото метода. Включите метод.
10. /admin → Настройки магазина → Приём заказов: включите после настройки.
    Флаг окружения и этот переключатель нужны ОБА. Сам флаг true не
    включает приём заказов автоматически. Stars не заменяют вашу схему.
11. До реальных продаж проверьте бот с двумя аккаунтами: заказ, скриншот,
    подтверждение, отказ с комментарием, выдача, очередь и перезапуск.

ОБНОВЛЕНИЕ СТАРОЙ ВЕРСИИ
Сделайте резервную копию в админке перед redeploy. База версии 1 автоматически
обновляется до версии 2 с полем причины отказа. Заказы и настройки сохраняются.
После миграции не откатывайте старый код без восстановления подходящего backup.
